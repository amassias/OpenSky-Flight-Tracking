Key Features:
✓ Interactive flight tracking maps
✓ Real-time position updates (30s refresh)
✓ Altitude-colored trajectories (0-40k+ ft)
✓ Worldwide airport coverage (7,895 airports)
✓ Full airline names (5,765 airlines)
✓ Dark/light basemap themes
✓ Rotated aircraft icons with heading
✓ Full-map focus mode
✓ Zero CSV file creation
✓ Pure JSON communication
